# 技術検証：画面なしの Claude Code に MCP で案を作らせる

Slipper は AI を直接呼ばず、ボタンで画面なしの Claude Code（`claude -p`）を起動して、Slipper の MCP サーバー経由で案を受け取ります。その方式が成り立つかを確かめる検証です。製品のコードではありません。

## 動かし方

```sh
npm install
node run.mjs inline                    # 3案を並行で依頼（ページはプロンプトに埋め込む）
SLIPPER_EFFORT=medium node run.mjs inline
node run.mjs variants                  # ページを get_page で読ませる版
node run.mjs escape                    # Slipper 以外のツールを使えないことの確認
```

Claude Code にログイン済みであることが前提です。API キーは使いません。

## 結果（2026-09-26、Claude Code 2.1.283）

| 問い | 結果 |
|---|---|
| 合言葉つきで手元の MCP に接続できるか | できる。合言葉なし・誤りは 401。設定ファイルは 0600 の一時ファイルで渡し、コマンドラインに合言葉を出さない |
| Slipper 以外のツールを封じられるか | できる。`--tools ""` で Bash・Read・WebFetch などが存在しない状態になる。`--bare` は API キー必須のため使えない |
| 決めた形式で案が返るか | 返る。狙い・捨てたもの・元の資料にない要素の印（invented）つき。範囲外はツールがエラーを返し、AI が直して送り直す |
| 3案が30秒以内に揃うか | 思考の量（`--effort`）次第。下表 |

| 設定 | 3案が揃うまで | 1案あたりの出力 | 案の質 |
|---|---|---|---|
| Sonnet 5・既定 | 57〜99秒 | 数千トークン | 最も具体的（失敗したテストの中身まで描く） |
| Haiku 4.5・既定 | 64秒 | 4,500〜9,000トークン | 言葉が多く、発想が平凡 |
| Sonnet 5・medium | 約15秒 | 約1,000トークン | 十分。既定よりやや浅い |
| Sonnet 5・low | 約13秒 | 約700トークン | medium とほぼ同じ |

- 時間の大半は、AI が考えて書き出す時間。Claude Code の起動は1〜2秒
- 「OK」と返すだけの最小の依頼でも、ときどき35〜40秒待たされることがある（AI 側の混み具合）。30秒以内は保証できない
- 各試行は1〜2回ずつなので、数字は傾向として扱う

## 設計への反映

- ボタンからの依頼は **Sonnet 5 ＋ `--effort medium`** を初期値にする
- じっくり考えさせたいときは、既定の思考量で頼む選択肢を用意する（1分ほどかかる）
- ページの内容はプロンプトに埋め込み、往復を減らす。`get_page` は会話から頼むとき用に残す
- 案はできた順に表示し、AI 側が遅いときは待っていることを示す
